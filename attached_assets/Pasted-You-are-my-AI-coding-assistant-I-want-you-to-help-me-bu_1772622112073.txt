### Requirements

1. **Purpose**:  
   - User types raw daily standup notes:  
     - Yesterday's Work  
     - Today's Plan  
     - Blockers

2. **Tech Stack**:  
   - Frontend: React (Vite) + Tailwind CSS + Framer Motion (modern UI)  
   - Backend: Node.js + Express

     - ✅ Completed – green

     - ⚠ Blockers – red/orange

   - Smooth animations and modern card UI using Framer Motion  
   - Responsive design for desktop and tablet  

4. **Backend Features**:  
   - `/generate` endpoint: accepts user input + optional commits → AI → formatted summary

5. **AI Prompt Logic**:  
   - AI input: raw standup notes + optional commits

     ```json
     {
       "summary": "formatted professional summary with emojis",
       "weak_areas": "list of weak points detected in tasks"
     ```  
