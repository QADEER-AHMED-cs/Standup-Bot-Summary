## Packages
date-fns | Formatting timestamps beautifully
framer-motion | Smooth entry animations for the standup feed
lucide-react | Icons for the UI

## Notes
The application requires `date-fns` for human-readable dates and `framer-motion` for polished UI transitions. Both should already be in the base stack, but are listed here to be explicit.
Assumes the API returns the summaries as strings in `summaryCompleted`, `summaryPlanned`, and `summaryBlockers`.
